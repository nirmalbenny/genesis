# UI kit (`./genesis/ui.css`) and components (`./genesis/ui`), provided at run time; never write them
Genesis's look (coral, navy, Inter). src/main.js imports the kit before App: `import "./genesis/ui.css"`.
Build the UI from these components (shadcn-vue's API): `import { Button, Card } from "./genesis/ui"` ("../genesis/ui" from src/components). Every component takes class and native attributes. Write no CSS that restyles them.
- `Button` (variant: default | secondary | outline | ghost | destructive | link; size: default | sm | lg | icon | icon-sm; as="a"); `Badge` (variant: default | secondary | outline | destructive | success | warning | info).
- `Card` > `CardHeader` > `CardTitle`, `CardDescription`; `CardContent`, `CardFooter`; `Separator`; `Skeleton` (size via style).
- Forms: `Label`; v-model on `Input`, `Textarea`, `NativeSelect` (`<option>` children), `Checkbox`, `Switch`, `Select` > `SelectTrigger` > `SelectValue` (placeholder), `SelectContent` > `SelectItem` (value).
- `Table` > `TableHeader`, `TableBody` > `TableRow` > `TableHead`, `TableCell`; `Avatar` (name, src).
- `Tabs` (v-model) > `TabsList` > `TabsTrigger` (value); `TabsContent` (value).
- Overlays; triggers take as-child around a Button: `Dialog` (v-model:open) > `DialogTrigger`, `DialogContent` > `DialogHeader` > `DialogTitle`, `DialogDescription`; `DialogFooter`, `DialogClose`. `Sheet` likewise (`SheetTrigger`, `SheetContent` side: right | left, `SheetHeader`, `SheetTitle`, `SheetDescription`, `SheetFooter`, `SheetClose`). `DropdownMenu` > `DropdownMenuTrigger`, `DropdownMenuContent` > `DropdownMenuLabel`, `DropdownMenuItem` (@select; variant: destructive), `DropdownMenuSeparator`. `Popover` > `PopoverTrigger`, `PopoverContent`. `Tooltip` > `TooltipTrigger`, `TooltipContent`.
- States: `Alert` (variant: default | destructive | success | warning) > `AlertTitle`, `AlertDescription` (errors: error.message in variant destructive); `Loading` (text); `EmptyState` (title, description, slot); `Stat` (label, value).
Classes: `.page` (root), `.header` (title left, actions right), `.stack`, `.row`, `.grid` (responsive card columns), `.spacer`, `.stats` (grid of `Stat`), `.table-wrap`, `.field` (label + control), `.list` > `.list-item` (`.clickable`, `.active`), `.chips` > `.chip` (`.active`) for filters, `.muted`, `.small`, `.truncate`, `.sr-only`. h1-h3, p and code are styled.
Variables: `--bg --surface --surface-muted --primary-soft --primary-hover --text --muted --border --input-border --primary --on-primary --ring --success --warning --danger --info --radius --font --font-mono --tint-amount --shadow` (`--tint-amount` is a percentage). Use them in layout CSS; for a look the user asked for, override them in :root in src/style.css (after the kit).
